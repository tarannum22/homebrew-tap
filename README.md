# tarannum22/homebrew-tap

Homebrew formulae for [watermelon-pgp](https://github.com/tarannum22/watermelon-pgp), a
self-hosted tool to manage OpenPGP keys and run folder encryption/decryption jobs.

```sh
brew install tarannum22/tap/watermelon-pgp
```

The formula is generated by the watermelon-pgp release workflow; don't edit it here.
